# Glass Deck 1.6.1

## Clipboard shelf

- New **Clipboard** tab: the last 60 text clips, newest first, with the most recently captured item on top.
- Click a row to put that clip back on the system pasteboard; the row reports "Copied back to clipboard" in the status strip.
- **Pin** keeps an item forever, above the unpinned history; **×** deletes a single clip; **Clear** empties everything including pinned items.
- Recording follows the system pasteboard by polling `NSPasteboard.changeCount` — no Accessibility permission, no event tap, no keystroke access.
- Items flagged `org.nspasteboard.ConcealedType`, `…TransientType` or `…AutoGeneratedType` (what password managers set) are skipped and never written to disk.
- History is stored at `~/Library/Application Support/GlassDeck/clipboard.json`, capped at 60 unpinned entries plus pinned ones, 100 000 characters per clip. Nothing is uploaded anywhere.
- The **Record clipboard** switch at the top of the tab turns capture off; already-captured items stay until cleared.

## Panel

- The tab bar is icon-only with per-segment tooltips. Seven labelled segments overflowed a 380 pt panel — the last label was clipped mid-character.
- Clipboard capture starts with the app, so a copy made anywhere is already in the shelf when the panel opens.

## Compatibility and packages

- macOS 14 or newer, universal binary (arm64 + x86_64), ad hoc signed, not notarized.
- DMG installer, ZIP app bundle and a SHA256 checksum file.
- The Xcode build embeds the WidgetKit extension; `build-app.sh` (SwiftPM) still ships the app without the widget.

## Validation

- Offscreen layout harness renders all seven tabs to PNG (plus the empty clipboard state) with a seeded history, confirming the icon tab bar fits and rows truncate instead of widening the panel.
- SwiftPM release build and the Xcode universal build both compile the new tab; `npm test` still passes for the web assets.
- Clipboard capture, pin ordering and persistence were exercised through the store API; interactive pasteboard capture was checked by copying text between apps.
