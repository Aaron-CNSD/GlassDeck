Stop hunting through System Settings. Glass Deck puts the controls you reach for every day one click away.

⌘K command palette

Every switch, tool and tab behind one search field. Type dark or 截图, arrow down, hit return — the panel answers to English and Chinese without changing the language.

🎛️

11 system switches

Dark mode, hidden files, keep-awake, mute, auto-hide dock and more — flip them in a tap, or search for the one you need.

🎬

Scenes

One click for the whole job: Present clears the desktop, Dock and menu bar; Focus quiets everything down. Reachable from the menu bar too.

📈

Live monitoring

Real-time CPU, memory and network throughput, updating every second via public APIs.

🪟

Window manager

List running apps, bring any to the front, or force-quit the ones macOS won't let you close.

🗑️

Cache cleaner

Scan and clear Xcode DerivedData, Homebrew, CocoaPods and SwiftPM caches — with a freed-space report.

🔤

Clipboard OCR

Extract text from any screenshot using the Vision framework, and drop it back into your clipboard.

Quick launch

Pin your favorite URLs, commands and files for instant one-click access.
