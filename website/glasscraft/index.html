iPhone / iPad 安装流程

  1. 解压下载的 ZIP，找到 IPA。按上游最新文档使用 SideStore / AltStore 或兼容系统上的 TrollStore 侧载。
  2. 按上游说明准备 JIT 与内存权限。普通未越狱设备可能需要电脑辅助，是否能运行取决于系统版本。
  3. 打开原生启动器，在账号列表点击添加，选择 Local Account / 本地账号，输入 3–16 位用户名。该模式不登录 Microsoft，不能进入要求正版验证的服务器。
  4. 选择版本，确认运行时，先测试原版，再导入兼容的模组、整合包与光影。

基础设计面向 iOS / iPadOS 14 及以上的受支持设备；这不代表所有后续系统版本都已验证。较新的 iPad、充足内存与兼容的 JIT 方案体验更好。

GETTING STARTED

从下载，到进入世界。

  1. 目前从 GitHub 获取本分支源码，或前往上游正式发行页体验原生引擎。上游 IPA 不等于 GlassCraft 安装包。
  2. 先核对 iOS 版本与 JIT 支持，再按官方说明侧载。使用自己的证书；本项目不提供企业证书。
  3. 在原生启动器使用有 Java 版授权的 Microsoft 账号登录，选择游戏版本与对应的 iOS 运行时。
  4. 先启动原版，再添加相同版本与加载器的模组。整合包使用内置 Modrinth 入口。
  5. 光影 ZIP 放入 shaderpacks，安装兼容的 Iris / OptiFine 后启用。复杂光影可能无法运行。
