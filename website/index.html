A FEW THINGS TO KNOW

开始之前，
你可能想知道。

Windows、Linux 或 iPhone 可以使用吗？

当前 GCL 仅提供 macOS 13+ 应用。JAR 是这个原生 Mac 应用的入口，并不提供跨平台 Java 引擎。目前没有可安装的 GCL iOS IPA。

本地用户名能加入所有服务器吗？

不能。本地模式可用于允许离线账号的服务器，无法进入要求 Microsoft 正版验证的服务器。房间联机还要求双方游戏、加载器与模组匹配。

陶瓦联机需要做什么准备？

首次需要在系统安装器中完成陶瓦组件安装，并按 macOS 提示授权本地网络访问。房主进入存档、对局域网开放后创建房间，朋友输入房间码加入。真实跨网连接仍待验证，P2P 成功率取决于公共节点、NAT 与双方网络。

为什么这是 v0.1.0 开发预览？

这是 GCL 独立项目的第一个开发版本。部分流程已完成自动化检查，但完整进入世界、游戏内皮肤及真实双机联机尚未完成验证。我们保留这些说明，帮助你按实际进度决定是否试用。

项目是否开源？如何参与？

GCL 采用 GPL-3.0 许可。陶瓦、CustomSkinLoader 等第三方组件保留各自的署名与许可。你可以通过 GitHub 提交问题或参与贡献，详细记录见仓库的 CONTRIBUTORS.md 与 CONTRIBUTING.md。
