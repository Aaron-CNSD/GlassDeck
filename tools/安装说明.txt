Glass Deck 安装说明
====================

【第一次打开被拦截？提示「已损坏」或「无法验证开发者」？】

这不是安装包坏了。本版本使用个人临时签名，没有经过 Apple 公证，
所以 macOS 会拦截所有从网上下载的未公证应用——这是系统的例行检查，
和文件本身是否完好无关。

■ 方法一：终端命令（最稳，一次搞定）

  1. 把左边的 "Glass Deck.app" 拖到右边的 Applications 文件夹
  2. 打开「终端」：启动台 → 其他 → 终端
  3. 粘贴下面这一行，回车，按提示输入开机密码：

     xattr -cr "/Applications/Glass Deck.app"

  4. 完成后直接双击应用即可，以后都不会再拦

■ 方法二：图形界面

  1. 把应用拖进 Applications
  2. 双击它，弹窗里点「完成」或「取消」
  3. 打开 系统设置 → 隐私与安全性，向下滚到底
  4. 找到「已阻止 Glass Deck」那一行，点「仍要打开」，输入密码


【首次使用请授权】

Glass Deck 有些开关必须借助系统自动化才能生效，首次点击会弹窗，
请点「允许」：

  · 控制「系统事件」 → 深色模式
  · 控制「访达」     → 清空废纸篓
  · 屏幕录制         → 截图 / 录屏

如果某个功能点了没反应，请点应用里的
  「工具」标签 →「权限自检」
它会逐项告诉你缺哪一项权限，并给出直达系统设置的按钮。


【使用提示】

  · 关闭窗口不会退出，应用常驻菜单栏（点菜单栏图标可打开面板）
  · 「保持清醒」会在后台运行 caffeinate，关掉开关即停止
  · 右键菜单栏图标可切换「简版 / 完整面板」和语言
